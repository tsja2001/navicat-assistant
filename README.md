# Assistant

Assistant 是一个 Windows x64 桌面助手。切到记事本、浏览器或其他应用，按一次快捷键，就能把当前可见题目交给 DeepSeek 识别，并在桌面提示条中阅读答案。发布包自带 .NET 10 桌面运行时。

## 三步开始

1. 双击 [Assistant.exe](dist/Assistant/Assistant.exe)，或双击项目根目录的 [run-probe.cmd](run-probe.cmd)。若显示「已暂停」，点「启用 Assistant」。
2. 在主窗口「DeepSeek OCR 密钥」中输入自己的 API Key，点「应用」。想让下次启动也能使用，先勾选「记住密钥」。
3. 打开记事本，输入「一年有几个月？」，点一下题目所在行，同时按 **Ctrl + Alt + O**。右下角会显示进度和答案，把鼠标放在答案上滚动即可看全文。

关闭主窗口会收起到托盘。要完全退出或更换版本，右键托盘里的 **Assistant → 退出**。

## 管理 OCR 密钥

| 想做什么 | 在主窗口怎么操作 |
|---|---|
| 只在本次使用 | 输入密钥，保持「记住密钥」未勾选，点「应用」 |
| 保存或替换密钥 | 输入密钥，勾选「记住密钥」，点「应用」 |
| 取消保存，本次继续用 | 取消「记住密钥」，点「应用」 |
| 立即停止使用并删除 | 点 **删除 OCR 密钥**。看到「OCR 密钥已删除」即完成，下次需重新输入 |

保存位置是当前 Windows 用户的凭据管理器。「删除 OCR 密钥」会移除该条本机凭据、清空本次使用的密钥和输入框，并取消正在进行的截图答题请求。DeepSeek 平台上的 Key 仍由账号持有人管理。Navicat、Word 使用的文本模型密钥在「设置 → AI 与提示词」单独管理。

## 截图和答案

- **截哪里**　默认截当前一块显示器，向 `deepseek-flash` 发送全图和局部图。只想发送记事本窗口，可在「设置 → AI 与提示词 → 屏幕 OCR → 截图范围」选择「仅前台窗口」。
- **怎样选题**　先让题干和选项完整可见。在可编辑文档中，点进目标题目可以帮助定位。有可靠文字光标时，局部图会标出它的位置。遇到多题难以区分时，可只留一道题再截图。主窗口的「屏幕识别原文」可用来核对。
- **怎样看全文**　悬浮提示条显示「完整 AI 建议」中的截图答案正文，保留换行和代码缩进。鼠标滚轮、滚动条以及 **Win + PageUp / PageDown** 都可阅读长答案。要试续写，可以在记事本输入「请续写：今天阳光很好，我想」，把光标留在末尾再截图。
- **怎样调外观**　拖文字移动窗口，拖左上角或右下角调整宽高。右键「提示条外观…」可选背景颜色、调背景不透明度或点「全透明」，然后保存。文字单独着色。调整后的大小会保存，右键「回到任务栏」可复位位置。
- **录屏与隐私**　主窗口、设置窗口和提示条向 Windows 申请捕获排除。主窗口「输出通道」显示系统返回的状态，实际录制效果取决于捕获方式。截图在内存中处理，按快捷键答题会将图片发给模型；请选取可以发送的内容。

## 其他入口

| 默认快捷键 | 作用 |
|---|---|
| `Ctrl+Alt+S` | 暂停或恢复整套 Assistant |
| `Ctrl+Alt+O` | 识别当前屏幕并在提示条显示答案 |
| `Ctrl+Alt+C` | 获取当前题的完整答案并复制，随后可自行粘贴 |
| `Ctrl+Alt+A` | 分析当前 Navicat 选区、刷新 SQL 续写或分析 Word 光标处内容 |
| `Ctrl+Alt+R` | 生成或切换 Navicat 续写候选 |
| `Ctrl+Alt+V` | 回答剪贴板中的 SQL / 数据库题目 |
| `Ctrl+Alt+D` | 切换受控逐字输入，`Esc` 退出 |
| `Ctrl+Alt+M` / `Ctrl+Alt+P` | 启停手机页 / 切换手机黑屏模式 |

Navicat 优先通过 Win32 读取编辑器全文与光标位置。启用 MySQL 增强后可使用目录信息和受限的只读查询。普通 Word 文档首次按智能分析后才开启该文档的 AI 续写。手机页默认关闭，开启后用同一局域网的手机访问主窗口给出的带令牌地址，默认端口为 `17832`。功能细节见[数据库增强说明](docs/新需求-连接sql-提升体验/新需求-连接sql-提升体验.md)和 [Word 练习题说明](docs/需求2.md)。

## 常见问题

| 现象 | 检查方法 |
|---|---|
| 快捷键没反应 | 确认总开关和屏幕 OCR 已启用，再切回要识别的应用。若主窗口提示热键冲突，先退出另一份 Assistant，或在设置中改键。 |
| 能截图却没有答案 | 查看提示条的错误信息。若提示缺少密钥，在主窗口输入后点「应用」，再按快捷键。 |
| 识别到了其他题 | 在「屏幕识别原文」核对题干，把目标题目完整显示在窗口内，再用「仅前台窗口」重试。 |

## 开发与发布

源码在 `src/NavicatTextProbe`，回归自测在 `tests/NavicatTextProbe.SelfTests`。在 Windows 上安装 .NET 10 SDK 后，从本项目根目录运行以下 PowerShell 命令。

```powershell
dotnet build .\NavicatAssistant.slnx -c Release
dotnet .\tests\NavicatTextProbe.SelfTests\bin\Release\net10.0-windows\NavicatTextProbe.SelfTests.dll
.\build-and-publish.ps1 -SelfContained
```

本机已有独立 SDK 时，可使用 `.\build-and-publish.ps1 -DotnetPath .\dist\.build-tools\dotnet.exe -SelfContained`。发布前先从托盘退出正在使用目标目录的旧版。发布和启动统一使用 **`dist\Assistant\Assistant.exe`**。复制到别的 Windows x64 电脑时请复制整个 `dist\Assistant` 文件夹。

`.gitignore` 排除了编译中间文件、发布包、本机开发工具、运行时配置、日志和转储。项目目录中的 `config/settings.json` 包含本机偏好与手机访问令牌；`logs/` 可能包含 SQL 或文档上下文。维护文档与示例仍可纳入版本控制。
